# MedicalField

Sistema em desenvolvimento para registro e consulta de atendimentos médicos de emergência.

## Estrutura inicial

- `banco/`: definição do banco de dados PostgreSQL;
- `servicos/cadastros-node/`: serviço de cadastros e autenticação;
- `servicos/atendimentos-python/`: serviço de atendimentos;
- `servicos/sync-go/`: serviço de sincronização;
- `web/`: interfaces web do projeto.

## Tecnologias previstas

- PostgreSQL
- Node.js e Express
- Python e FastAPI
- Go
- HTML, CSS e JavaScript

O projeto ainda está em fase inicial. As APIs e interfaces serão implementadas de forma incremental.
